# veda_learning

Guru reference recordings for the nine Rigveda starter lessons are bundled as OGG assets in `assets/audio/guru_reference/` and played from the corresponding lesson page. The upload order supplied by the Guru is recorded in `../content/guru_reference_audio_mapping.json`; an exact duplicate recording was excluded.

A new Flutter project.
