# Word-level Guru audio

Separate clips are optional. The app can play a word from the existing whole-shloka OGG by using the saved start and end times. Open **Admin · Guru content**, select a lesson, play its Guru recording, mark each word's start and end, then save. The learner screen uses those ranges for tap-to-play and sequential word highlighting.

If separate word clips are available, the app also accepts `assets/audio/guru_words/<lesson-id>/word-01.ogg`, `word-02.ogg`, and so on. Word order follows the whitespace-delimited published Sanskrit text.
