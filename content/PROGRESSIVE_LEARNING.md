# Progressive mantra learning

The learner app now exposes a progressive Ṛgveda practice library with Kanchi/Sringeri profile selection, Maṇḍala → Sūkta → mantra navigation, bookmarks, and resume position. Its interface strings for the progressive flow are available in English, Hindi, Kannada, Tamil, Telugu, Malayalam, Marathi, Bengali, Gujarati, and Punjabi through the existing language selector. It displays the original stored Saṃhitā and Padapāṭha forms unchanged. It lists only profile text variants with reviewed segmentation and cleared rights. Each mantra carries persisted current/unlocked word position, completed words, bookmark and final completion state. Each word, combined recitation, and full-mantra attempt is stored separately with profile, order/mode, learner audio, evaluation status, and report. The progress dashboard summarizes attempts, started/completed mantras, learned words, bookmarks, and Maṇḍala totals per profile.

Workflow: listen to a validated word clip; record and evaluate the currently unlocked word; retry until the selected-profile provider explicitly passes; combine contiguous learned words and evaluate; repeat that sequence until all words are combined; record and evaluate the full mantra; retain the final report. A word unlocks only on explicit provider `transcription.evaluation_passed=true`, a completed word alignment, and no validated phonetic/accent findings. Missing evaluation does not unlock or count as a failure; retry remains available. The full-mantra report is included in attempt history.

API: `GET /api/recitation/learning-mantras?profile=Kanchi&mandala=1` lists available mantras; `GET /api/recitation/{reference}/learning?profile=...` returns word/audio/progress availability; `POST /{reference}/resume`, `PUT /{reference}/bookmark`, `POST /{reference}/attempt`, and `GET /{reference}/attempts` persist state and practice history. Attempt mode is `word`, `combined`, or `full_mantra`.

Current limitation: the 20 supplied PDFs remain uncertain extraction candidates, all generated Padapāṭha segmentation is unavailable, no text variants have been reviewed/rights-cleared, and no production speech engine or audio assets are configured. Therefore the available mantra list is currently empty for both profiles and all ten Maṇḍalas. No content, word audio, evaluation result, or progress is synthesized. Once reviewed source records and validated audio/evaluation providers are added, all matching imported mantra variants become available automatically. Language selection uses the existing app-level language selector; mantra Sanskrit remains source text.
